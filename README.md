# LuxeEstate - Property Management System
A comprehensive web application following the MVC architecture designed to
simplify the process of buying, selling, and renting real estate properties. The system enables
users, landlords, and real estate companies to connect in one platform, providing
essential features such as property listings, purchase, sale, rental, and development.

### Objectives
1. As a real estate company, I want to be able to bid on development requests.
2. As a general user, I want to keep track of interesting properties.
3. As a user, I want to be able to find rental properties
4. As a landowner, I want to sell or rent out my property
5. As a buyer, I want to be able to buy a property


### Tech Stack
MERN - MongoDB, ExpressJS, React, NodeJS

CSS Components from ChakraUI
